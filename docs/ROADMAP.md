> **Project:** SIMAK — Sistem Informasi dan Manajemen Akademik
> **Stack:** TanStack Start + PostgreSQL + Drizzle ORM + shadcn/ui + Tailwind v4
> **Document Status:** Living document. Update tracks as they are completed.

## Phase 1: Foundation & Core Infrastructure

This phase establishes the project scaffold, local dev environment (Docker Compose with PostgreSQL), database schema, authentication system, git hooks for code quality, core layout plumbing, and all dev tooling. Every subsequent track depends on these foundations.
