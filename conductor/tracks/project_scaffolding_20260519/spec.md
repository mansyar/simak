# Track: Project Scaffolding

## Description

Initialize the TanStack Start project with all tooling, configure Tailwind CSS v4 with shadcn/ui, define the folder structure, set up environment validation, create the Docker build pipeline, configure local dev environment via Docker Compose, and set up git hooks for code quality.

## Dependencies

None (first track of the project).

## Package Manager

`pnpm` (used for all dependency management and scripts).

## Version Requirements

- Node.js >= 20
- pnpm >= 9
- PostgreSQL >= 16
- Docker (for local dev and production build)

## Scaffolding Approach

Use `pnpm create @tanstack/start` to generate the initial project scaffold in the project root directory, then remove all boilerplate/template code (default routes, demo pages, icons, assets) and customize the generated config files to match this spec.

## Files to Create

| File | Purpose |
|---|---|

| `eslint.config.js` | ESLint flat config: TypeScript rules, React rules, import ordering, `@/` alias resolution |
| `.prettierrc` | Prettier config: single quotes, trailing commas, 100 print width, consistent with ESLint rules |
| `components.json` | shadcn/ui configuration (generated by `npx shadcn@latest init`) |

## CSS Custom Properties Specification

The `src/app/global.css` file must define CSS custom properties using shadcn/ui conventions with Tailwind v4-compatible syntax. The token-based system includes:

| Token | Light Value | Dark Value | Purpose |
|---|---|---|---|
| `--background` | `oklch(1 0 0)` | `oklch(0.145 0 0)` | Page background |
| `--foreground` | `oklch(0.145 0 0)` | `oklch(0.985 0 0)` | Text color |
| `--card` | `oklch(1 0 0)` | `oklch(0.145 0 0)` | Card background |
| `--card-foreground` | `oklch(0.145 0 0)` | `oklch(0.985 0 0)` | Card text |
| `--primary` | `oklch(0.205 0.042 265)` | `oklch(0.922 0.031 265)` | Primary brand |
| `--primary-foreground` | `oklch(0.985 0 0)` | `oklch(0.205 0.042 265)` | Primary text |
| `--secondary` | `oklch(0.965 0.013 265)` | `oklch(0.269 0.027 265)` | Secondary surface |
| `--secondary-foreground` | `oklch(0.205 0.042 265)` | `oklch(0.985 0 0)` | Secondary text |
| `--muted` | `oklch(0.965 0.013 265)` | `oklch(0.269 0.027 265)` | Muted surface |
| `--muted-foreground` | `oklch(0.585 0.023 265)` | `oklch(0.695 0.019 265)` | Muted text |
| `--accent` | `oklch(0.965 0.013 265)` | `oklch(0.269 0.027 265)` | Accent surface |
| `--accent-foreground` | `oklch(0.205 0.042 265)` | `oklch(0.985 0 0)` | Accent text |
| `--border` | `oklch(0.922 0.031 265)` | `oklch(0.269 0.027 265)` | Border color |
| `--ring` | `oklch(0.585 0.023 265)` | `oklch(0.695 0.019 265)` | Focus ring |
| `--success` | `oklch(0.527 0.154 150)` | `oklch(0.627 0.194 150)` | Pass/green |
| `--warning` | `oklch(0.769 0.188 70)` | `oklch(0.795 0.184 70)` | Revise/amber |
| `--error` | `oklch(0.577 0.245 27)` | `oklch(0.66 0.22 27)` | Overdue/red |
| `--info` | `oklch(0.546 0.245 262)` | `oklch(0.685 0.22 262)` | Consultation/blue |

All tokens use `oklch()` for perceptual uniformity and Tailwind v4 compatibility. The `@media (prefers-color-scheme: dark)` or `.dark` class selector triggers the dark values.

## Definition of Done

- `pnpm run dev` starts the dev server without errors
- `pnpm run build` produces a production build
- A placeholder page renders at `localhost:3000` with Tailwind v4 styles (both light and dark mode)
- `docker compose up` starts PostgreSQL on port 5432
- `docker build` succeeds with the multi-stage Dockerfile
- Environment variables validated via Zod throw meaningful errors when missing
- `git commit` triggers lint-staged (eslint, prettier, typecheck, modularity check)
- `git push` triggers full typecheck and vitest coverage
- `npx shadcn@latest init` completes and `shadcn add button` installs a Button component successfully
- i18n types are generated on `pnpm run dev` — `t('key')` is type-safe from the first component
- Theme toggle switches between light and dark modes; preference persists across sessions
